Все методы не изменяют исходный массив, а возвращают новые данные или значения.

Ключевые фрагменты кода с пояснениями

1. Класс TransactionAnalyzer – общая структура

```javascript
class TransactionAnalyzer {
  constructor(transactions) {
    this.transactions = transactions;
  }
  // методы анализа...
}
```

Пояснение:
Класс инкапсулирует данные и поведение. Массив транзакций хранится в свойстве transactions, а каждый метод работает с ним через this.transactions.

2. Получение уникальных типов с помощью Set

```javascript
getUniqueTransactionTypes() {
  return [...new Set(this.transactions.map(t => t.transaction_type))];
}
```

Пояснение:

· map извлекает значения поля transaction_type из каждого объекта.
· new Set(...) оставляет только уникальные значения.
· Оператор spread ... преобразует Set обратно в обычный массив.

Этот подход гарантирует, что в результирующем массиве не будет дубликатов.

3. Вычисление общей суммы с reduce

```javascript
calculateTotalAmount() {
  return this.transactions.reduce((sum, t) => sum + t.transaction_amount, 0);
}
```

Пояснение:
Метод reduce проходит по всем элементам, аккумулируя сумму в переменной sum. Начальное значение 0 обеспечивает корректный результат для пустого массива.

4. Фильтрация по дате с опциональными параметрами

```javascript
calculateTotalAmountByDate(year, month, day) {
  return this.transactions
    .filter(t => {
      const d = new Date(t.transaction_date);
      if (year !== undefined && d.getFullYear() !== year) return false;
      if (month !== undefined && d.getMonth() + 1 !== month) return false;
      if (day !== undefined && d.getDate() !== day) return false;
      return true;
    })
    .reduce((sum, t) => sum + t.transaction_amount, 0);
}
```

Пояснение:

· Параметры year, month, day необязательны – если аргумент не передан, он равен undefined, и проверка по нему пропускается.
· Даты преобразуются в объект Date, чтобы корректно сравнить год, месяц (с поправкой +1, так как в Date месяцы нумеруются с 0) и день.
· Сначала фильтруются подходящие транзакции, затем через reduce вычисляется сумма.

Такой подход даёт гибкий расчёт за любой временной интервал.

5. Определение месяца с наибольшим количеством транзакций

```javascript
findMostTransactionsMonth() {
  if (this.transactions.length === 0) return null;
  const monthCount = {};
  this.transactions.forEach(t => {
    const month = new Date(t.transaction_date).getMonth() + 1;
    monthCount[month] = (monthCount[month] || 0) + 1;
  });
  return Object.keys(monthCount).reduce((a, b) =>
    monthCount[a] > monthCount[b] ? a : b
  );
}
```

Пояснение:

· Если массив пуст, возвращается null – корректная обработка граничного случая.
· forEach подсчитывает количество транзакций в каждом месяце, сохраняя результат в объект { месяц: количество }.
· Далее Object.keys() получает массив месяцев, и reduce сравнивает их по количеству, возвращая месяц-лидер.

6. Безопасное обращение к среднему значению

```javascript
calculateAverageTransactionAmount() {
  if (this.transactions.length === 0) return 0;
  return this.calculateTotalAmount() / this.transactions.length;
}
```

Пояснение:
Перед делением проверяется длина массива. Это защищает от NaN для пустого набора данных.

7. Метод mapTransactionDescriptions – пример использования map

```javascript
mapTransactionDescriptions() {
  return this.transactions.map(t => t.transaction_description);
}
```

Пояснение:
map создаёт новый массив, в котором каждый элемент — только описание транзакции. Исходный массив объектов остаётся нетронутым.

8. Документирование JSDoc (пример)

```javascript
/**
 * Возвращает массив уникальных типов транзакций.
 * @returns {Array<string>} уникальные типы
 */
```

Пояснение:
Каждый метод снабжён подобным комментарием с указанием параметров и возвращаемого значения. Это позволяет автоматически генерировать документацию и улучшает читаемость кода.

Ответы на контрольные вопросы

1. Какие методы массивов можно использовать для обработки объектов в JavaScript?

· map() – преобразование каждого объекта (например, извлечение нужного поля).
· filter() – отбор объектов по условию (по дате, типу, сумме).
· reduce() – свёртка объектов в одно значение (сумма, статистика).
· find() – поиск первого объекта, удовлетворяющего условию.
· forEach() – выполнение действий без создания нового массива.
· sort() – сортировка объектов по определённому критерию.
· some() / every() – проверка наличия хотя бы одного / всех по условию.

Все эти методы не мутируют исходный массив (кроме sort), что соответствует функциональной парадигме.

2. Как сравнивать даты в строковом формате в JavaScript?

Строки формата "ГГГГ-ММ-ДД" можно сравнивать напрямую как строки, так как их лексикографический порядок совпадает с хронологическим. Однако в работе применяется преобразование в объект Date через new Date(dateString). Это более универсально и надёжно, так как позволяет работать с разными форматами и учитывать временные зоны. Сравнение объектов Date сводится к сравнению миллисекунд.

3. В чём разница между map(), filter() и reduce() при работе с массивами объектов?

· map() – создаёт новый массив той же длины, где каждый элемент получен преобразованием исходного объекта. Пример: массив описаний транзакций.
· filter() – возвращает массив, содержащий только те объекты, которые прошли проверку (предикат возвращает true). Размер результирующего массива ≤ исходного. Пример: только дебетовые транзакции.
· reduce() – перерабатывает всё содержимое массива в одно итоговое значение (число, объект, строка и т.д.). Пример: сумма всех сумм транзакций.

map → «один к одному», filter → «отбор», reduce → «агрегация».
