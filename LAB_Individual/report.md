# Менеджер книжной библиотеки

Интерактивное веб-приложение для управления личной библиотекой. Позволяет добавлять, редактировать и удалять книги, выполнять поиск по названию или автору, фильтровать по статусу (прочитана / не прочитана) и сортировать по названию или году. Реализовано на чистом JavaScript (Vanilla JS) с модульной архитектурой, без сторонних фреймворков. Интерфейс адаптивен и сопровождается анимациями.

---

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd library-manager
   ```

2. Запустите локальный веб-сервер.  
   Это необходимо, так как используются ES6-модули. Например:
   - **С помощью Python** (версия 3):
     ```bash
     python -m http.server 8000
     ```
   - **С помощью Node.js** (если установлен `http-server`):
     ```bash
     npx http-server
     ```
   - **Через расширение Live Server** в VS Code.

3. Откройте браузер и перейдите по адресу:
   ```
   http://localhost:8000
   ```

Зависимости отсутствуют — приложение работает на чистом HTML, CSS и JavaScript.

## Описание проекта

### Цель
Продемонстрировать навыки работы с DOM, событиями, валидацией, массивами объектов и модульным кодом на JavaScript.

### Основные функции

- **Добавление книги**  
  Модальное окно с полями: название, автор, год, жанр, статус. Все поля обязательны, кроме статуса.

- **Редактирование и удаление**  
  У каждой карточки книги есть кнопки «Редактировать» и «Удалить». При удалении появляется запрос подтверждения.

- **Поиск в реальном времени**  
  Поле ввода принимает часть названия или автора — список обновляется мгновенно.

- **Фильтрация по статусу**  
  Выпадающий список: «Все статусы», «Прочитана», «Не прочитана».

- **Сортировка**  
  Возможность сортировать книги по названию (А–Я / Я–А) или году (по возрастанию / по убыванию).

- **Валидация форм**  
  Проверка обязательных полей, корректного года (число от 1000 до текущего) и жанра. Ошибки отображаются под формой.

- **Адаптивный интерфейс**  
  Сетка карточек перестраивается под размер экрана. Все элементы удобны на мобильных устройствах.

- **Анимации**  
  Карточки появляются с плавной анимацией, модальное окно выезжает с эффектом слайда.

## Особенности реализации

- **Модульный подход**: код разделён на класс управления данными, функции UI и утилиты.
- **ES6-импорты/экспорты** (`type="module"`).
- **Делегирование событий** на контейнере книг для эффективной работы с динамическими элементами.
- **Адаптивная вёрстка** с использованием CSS Grid и Flexbox.
- **Чистый JavaScript** без сторонних фреймворков.
